# -KHSR-Digital-Library
Sistem Informasi Perpustakaan Pondok Pesantren Universitas Muhammadiyah Semarang merupakan website yang dibuat untuk membantu pengelolaan data perpustakaan secara digital. Sistem ini memudahkan pengurus dalam mengelola data buku, anggota, serta proses peminjaman dan pengembalian buku agar lebih rapi, cepat, dan efisien dibanding pencatatan manual.
# LATAR BELAKANG
Perkembangan teknologi informasi saat ini sangat pesat dan telah memberikan banyak kemudahan dalam berbagai bidang, termasuk dalam bidang pendidikan. Salah satu pemanfaatan teknologi informasi adalah dalam sistem pengelolaan perpustakaan. Perpustakaan di Asrama K.H Sahlan Rosjidi Universitas Muhammadiyah Semarang masih menggunakan sistem pencatatan manual dalam pengelolaan buku dan peminjaman. Hal ini sering menimbulkan beberapa masalah seperti kesulitan dalam mencari data buku, pencatatan peminjaman yang kurang terorganisir, serta kemungkinan kehilangan data. Oleh karena itu, diperlukan sebuah sistem informasi berbasis website yang dapat membantu pengelolaan perpustakaan menjadi lebih efektif dan efisien. Website ini diberi nama KHSR Digital Library.
# KONSEP WEBSITE
Website KHSR Digital Library merupakan sistem informasi perpustakaan berbasis web yang membantu proses pengelolaan secara digital.
